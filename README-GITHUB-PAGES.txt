# School in 2080 — GitHub Pages

This is the static website extracted from the Replit project.

## Publish
1. Create a new public GitHub repository, for example `school-in-2080`.
2. Upload the CONTENTS of this ZIP to the repository root (not the ZIP itself).
3. In the repository, open Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select `main` and `/ (root)`, then Save.

The site uses browser speech synthesis and speech recognition where supported.
Microphone recognition requires browser permission and is not available in every browser.
